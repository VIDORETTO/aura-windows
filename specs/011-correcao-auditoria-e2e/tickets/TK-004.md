Gerar tabela Rust no build de aura-app a partir das entradas string desses dicionarios, com erro de build para entrada invalida; serde_json build-dependency permissiva ja usada no workspace. Comandos embutidos sao localizados na leitura/expansao conforme idioma atual, mantendo nomes canonicos, enabled e banco; comandos do usuario nunca sao traduzidos nem sobrescritos. Metadados opcionais de rotulo de anexo (nome e counts tipados) permitem UI traduzir/pluralizar sem alterar filename/conteudo/label canonico; compatibilidade serde default/skip e golden ADR0009. Contagens sao extraidas somente do resumo gerado internamente conhecido, nao de nome/conteudo arbitrario. Troca idioma atualiza titulos/tray existentes, sugestoes/chips e catalogo, sem restart.
