## Decisões

Escopo adicional reconhecido 03/10 (execução nativa): o recomendado Whisper Turbo no worker CPU-only (sem feature vulkan; build MSVC) levou 160 s (4 threads) e ~100 s (8 threads) para 3 s de fala e o app falhou com `transcription timed out`, embora a transcrição estivesse correta. Recomendar modelo grande exige worker com inferência em GPU: `Hardware.gpu_inference` vem de `aura-worker --capabilities`; sem GPU utilizável, regra CPU (Parakeet V3). Worker usa ~núcleos físicos no whisper. 006 AC-002 preservado: GPU dedicada só vale quando o worker a usa. Escopo adicional reconhecido AppStore downloads: DownloadError::Cancelled tem wire string literal cancelled; cancelamento intencional não deve virar aviso de falha. state/app.ts pertence à fatia para essa classificação, sem novo formato. Retry guarda snapshot do status anterior até próximo evento; language change não troca modelo já solicitado.

Preservar contrato006 AC013. Publicar Failed model_missing no Host para botão e hotkey; card acessível inline sem captura automática. voiceModels recomendado, download/progresso/cancel/retry e voiceSelect ao concluir para persistir. Installed pode selecionar sem baixar. Backend indisponível é erro worker_missing, nunca Fake vazio fora demo/testes; Cloud fallback continua. Bundle já prevê worker real.
